Clio for Windows (unsigned build)

Windows SmartScreen may warn "Windows protected your PC" because this build is not
code-signed. Verify the download against SHA256SUMS-windows.txt on the release page, then choose
"More info" > "Run anyway". Details: docs/releasing.md in the source repository.

Zip: extract anywhere and run Clio.exe. Installer: per-user, no administrator needed.
clio-mcp-bridge.exe is launched by Claude Desktop or Claude Code when you enable MCP in Clio.
